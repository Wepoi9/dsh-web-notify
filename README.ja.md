# dsh-web-notify

[English](README.md) | 日本語

DeepSeek Harness（DSH）Web UI 用のコミュニティプラグインです。セッションの完了・エラー・ブロック・操作待ちをブラウザの Notification API 経由で OS 通知します。

> DeepSeek Harness 本体に同梱される公式プラグインではなく、コミュニティ管理の外部プラグインです。

## 動作

Host 側で `notifyTurn` session projection を登録し、Web クライアントがセッション状態を監視します。次の場合に通知対象になります。

- 非表示セッションの turn が `completed` / `blocked` / `error` で終了
- セッションが `approval` / `question` / `plan-review` 待ちになる

対象の会話を表示中で、ページが visible・focused の場合は通知しません。

そのほかの挙動:

- `max-tokens` / `aborted` / `interrupted` は通知しない
- subagent セッションは通知しない
- turn 番号と interaction key で重複通知を抑制
- 同一更新の複数アクションは1件に集約
- 通知クリックで優先度の高い対象セッションを開く
- `Notification.permission === "granted"` の場合だけ通知

## 導入

依存関係を導入し、クライアント bundle を生成します。

```sh
npm install
npm run build
```

このリポジトリのローカル checkout を Web profile に追加します。

```sh
dsh plugin --profile web add <このリポジトリへの絶対パス>
```

追加後に DSH Web を再起動します。

## 設定

**Settings → General → ブラウザ通知** を開きます。

- 権限未決定: ブラウザ通知の許可を要求
- 許可済み: テスト通知を送信
- 権限取り下げ: ブラウザのサイト設定から変更

表示言語はブラウザの優先言語から決まり、DSH 本体の Language 設定変更には追随しません。最初の有効な言語が `ja` または `ja-*` なら日本語、それ以外なら英語を表示します。ブラウザの優先言語を変えた場合はページの再読み込みが必要です。

## プライバシーと通知内容

OS の通知センターやロック画面に通知内容が表示される場合があります。

通知は意図的に次の範囲へ制限しています。

- 汎用の `DSH` タイトルと、完了・エラー・承認待ちなどの短い状態（英語表示では Completed / Error / Waiting for approval に対応します）
- 集約通知の数量と汎用ラベル

セッション表示名・LLM 出力・コマンド本文・フルパスは通知に含めません。セッション名に顧客名や案件名が含まれても、OS のロック画面には表示されません。プラグインは専用の権限を宣言していません。参照するのはセッション ID と、完了・待ち受けの状態を表す列挙値（completed、error、blocked、approval など）だけで、OS 通知へ渡るのは汎用タイトルと固定の状態ラベル・定型文です。通知をクリックすると対象セッションが開く（プラグインが渡すのはそのセッション ID だけ）ため、識別はクリックで行います。

通知データを外部サービスへ送信せず、ブラウザの Notification API だけを使用します。

## ビルド・テスト

```sh
npm run build
npm run check
npm test
```

`npm run build` は esbuild で `lib/client.js` を再生成します。クライアントソース変更後は再ビルドしてください。

## 制約

- ブラウザ通知権限が必要で、権限は origin ごとに管理されます。
- DSH ページが読み込まれ接続が生存している間だけ通知できます。オフライン push 通知は実装していません。
- DSH は開発中のため、プレリリース間で拡張契約が変わる可能性があります。
- 表示言語はクライアントモジュール読み込み時に一度だけ決まります。ブラウザの優先言語を変えた後はページを再度読み込むまで反映しません。

## コントリビューション

バグ報告や範囲を絞った Pull Request を受け付けます。通知不具合では DSH バージョン、ブラウザ、OS、対象セッション状態、ページの visible/focused 状態を記載してください。
