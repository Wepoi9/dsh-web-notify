# dsh-web-notify

DeepSeek Harness（DSH）Web UI 用のコミュニティプラグインです。セッションの完了、エラー、ブロック、または操作待ちなどの状態変化を、ブラウザの Notification API を通じて OS の通知として受け取ることができます。

> **ご注意**: 本プラグインはコミュニティによって管理されており、DeepSeek Harness 本体の公式配布物には含まれていません。

### 動作仕様
Host 側で `notifyTurn` セッション投影を登録し、Web クライアントがセッションの状態を監視します。以下の条件で通知を発信します。

- **状態変化**: 非表示セッションの turn が `completed` / `blocked` / `error` で終了したとき。
- **操作待ち**: セッションが `approval` / `question` / `plan-review` などのユーザー応答待ち状態になったとき。

**通知の抑制と制御**:
- **アクティブ画面**: 対象の会話ページを既に表示しており、かつページがフォーカスされている場合は通知しません。
- **除外ケース**: `max-tokens` による終了、`aborted`（中断）、`interrupted`（割り込み）およびサブエージェントのセッションは通知対象外です。
- **重複抑制**: turn 番号と interaction key を使用して重複通知を防止し、同一タイミングの複数アクションは1件に集約します。
- **クイックアクセス**: 通知をクリックすると、優先度の高い対象セッションを即座に開きます。
- **権限管理**: ブラウザの通知権限が `granted`（許可）である場合のみ動作します。

### 導入方法
1. **ビルド**:
   ```sh
   npm install
   npm run build
   ```
2. **プロファイルへの追加**:
   リポジトリをローカルにチェックアウトし、以下のコマンドで Web プロファイルに追加します。
   ```sh
   dsh plugin --profile web add <このリポジトリへの絶対パス>
   ```
3. **適用**: DSH Web を再起動してください。

### 設定
**Settings $\rightarrow$ General $\rightarrow$ ブラウザ通知** から設定可能です。
- **権限未決定**: ブラウザに通知許可を要求します。
- **許可済み**: テスト通知を送信し、動作を確認できます。
- **権限取り下げ**: ブラウザのサイト設定から変更してください。

**表示言語について**: ブラウザの優先言語設定に基づきます（`ja` または `ja-*` で日本語、それ以外は英語）。言語設定を変更した場合は、ページの再読み込みが必要です。

### プライバシーと通知内容
OS の通知センターやロック画面でのプライバシーを保護するため、通知内容を最小限に限定しています。

- **通知内容**: 汎用タイトル `DSH` と、短い状態ラベル（例：`完了` / `承認待ち`）および集約数のみを表示します。
- **非表示項目**: セッション名、LLM の出力、コマンド本文、フルパスなどは**一切含めません**。これにより、ロック画面などから機密情報が不必要に露出するリスクを低減しています。
- **データ送信**: 通知データを外部サービスへ送信することはありません。ブラウザ標準の Notification API のみを使用します。

### 開発者向け情報
- **ビルド**: `npm run build` により esbuild で `lib/client.js` が生成されます。
- **テスト**: `npm run check` および `npm test` で検証可能です。

### 制約
- **権限依存**: ブラウザの通知権限が必要です。権限は origin ごとに管理されます。
- **接続維持**: DSH ページが読み込まれ、接続が維持されている間のみ通知可能です（オフライン Push 通知には非対応）。
- **言語反映**: 言語判定はモジュール読み込み時に一度だけ行われます。
